--- css_mode: evening --- {%- comment -%} The notes edition — the evening document. A standalone document, like twilight.html and folio.html: the edition replaces the standing frame (masthead, reading grid, colophon) rather than wearing it. `_includes/head.html` is shared; the chrome below is the edition's own, composed from _includes/notes/. The page is assembled in three moves, in this order: essay the note's rendered content, once, through note_edition — every margin note, sidenote and footnote becomes edition marginalia AT its source passage (_plugins/notes_edition.rb) contents the rail, derived from the ids kramdown rendered in that essay — never a second outline that can drift graph captured once from site.data.notes_graph (built by _plugins/bidirectional_links_generator.rb, in memory — a build writes nothing into the source tree) and rendered by notes/connections.html `` is deliberate: _includes/link-previews.html fetches a linked note into an iframe and reads its `` element for the hover preview. That coupling is recorded in design/architecture.org as phase-5 work — resolve it there, not incidentally here. A note's front matter, for whoever writes one: title, author, last_date the head, the sign-in, the dateline heroimgurl the hero image — also the og:image deck optional head line; else excerpt; else none kicker, kicker_subject optional; default "Notes / On learning" hero_alt, hero_label optional alt text and plate label for the hero Marginalia are authored in the note itself: the `margin` tag for an aside at its source, the `notes/side_link.html` include for a door out beside the passage that mentions its destination. A margin note whose only element is a picture is a WINDOW in the rail: no marker, no label. Give it a caption beside the image, and it keeps it: `…`. Both are spans because the note sits inside a paragraph — a block element there ends the paragraph, and the note is the thing that breaks. Anything block-level (a clip, a plate) belongs in the essay body, not in the margin. The layout owns no colours, sizes or links; those live in assets/css/components/evening.css and _data/nav.yml. {%- endcomment -%} {% include head.html %}
